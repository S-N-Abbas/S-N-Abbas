### 🤖 Inspectorobot

An Arduino/ESP32-based robotic inspection system controlled from a desktop application.

The project combines robotics, embedded programming and desktop software to provide remote control and camera-based inspection.

**Technologies:**

- Arduino
- ESP32-CAM
- C#
- WinForms
- WebView2
- L298 motor driver
- DC motors

### ⚡ NILM — Non-Intrusive Load Monitoring

A machine-learning project for identifying electrical appliances from electrical measurements.

The system uses an **ESP32** to collect electrical data and a Python/TensorFlow pipeline for machine-learning based appliance classification.

**Technologies:**

- ESP32
- C#
- Python
- TensorFlow
- VGG19
- Computer Vision
- Machine Learning
